# Roadmap — Sistema Operativo de Vida

## Vision

Construir un sistema de vida integrado que:
1. Me permita ser altamente productivo en todos mis circulos
2. Automatice tareas repetitivas con IA
3. Me ayude a aprender y crecer constantemente
4. Genere un modelo de negocio replicable que otros puedan usar

---

## Fase 1 — Fundacion (Junio - Julio 2026)

**Meta:** Tener el sistema base funcionando en los 3 dispositivos.

- [x] Crear estructura del repositorio
- [x] Definir los 5 circulos de vida
- [ ] Configurar Git en celular, PC personal y PC laboral
- [ ] Crear rutina diaria de sincronizacion (git pull/push)
- [ ] Completar primera semana de agenda con el template
- [ ] Definir metas del año en `personal/goals/2026-goals.md`
- [ ] Catalogar ideas de negocio actuales
- [ ] Configurar Platzi tracker

**Entregable:** Sistema funcionando, primer mes de agenda planificado.

---

## Fase 2 — Habitos y Productividad (Agosto - Septiembre 2026)

**Meta:** Instalar habitos que hagan el sistema sostenible.

- [ ] Rutina matutina de 30 min (revision + planificacion)
- [ ] Sistema de bloqueo de tiempo (time-blocking) en agenda
- [ ] Weekly review todos los domingos (30 min)
- [ ] Monthly review (1 hora el ultimo dia del mes)
- [ ] Tracker de habitos activo y en uso
- [ ] Avance visible en Platzi (minimo 3 cursos completados)
- [ ] Primera evaluacion de idea de negocio completada

**Entregable:** Habito diario de 30 min instalado, primer curso Platzi terminado.

---

## Fase 3 — Automatizacion Basica (Octubre - Noviembre 2026)

**Meta:** Automatizar las tareas mas repetitivas.

- [ ] Identificar las 5 tareas mas repetitivas en el trabajo
- [ ] Automatizar al menos 2 de ellas con scripts simples o IA
- [ ] Crear primer prototipo de herramienta de automatizacion
- [ ] Documentar el proceso para replicarlo
- [ ] Evaluar y priorizar ideas de negocio con el template
- [ ] Definir el modelo de negocio mas viable

**Entregable:** 2 automatizaciones funcionando, modelo de negocio definido.

---

## Fase 4 — IA y Emprendimiento (Diciembre 2026 - Febrero 2027)

**Meta:** Construir el primer MVP de automatizacion con IA.

- [ ] Elegir una idea de negocio para desarrollar
- [ ] Construir MVP (Producto Minimo Viable)
- [ ] Conseguir primeros 3 usuarios o clientes prueba
- [ ] Documentar el sistema para que otros puedan replicarlo
- [ ] Explorar opciones de monetizacion

**Entregable:** MVP funcionando con usuarios reales.

---

## Fase 5 — Escalado y Ventas (Marzo 2027 en adelante)

**Meta:** Convertir el sistema en un producto o servicio vendible.

- [ ] Refinar el producto basandose en feedback
- [ ] Crear material de ventas (landing page, demos)
- [ ] Definir estrategia de precio y distribucion
- [ ] Conseguir primeras ventas o contratos
- [ ] Sistematizar para que se maneje solo

**Entregable:** Primeros ingresos del proyecto de IA/automatizacion.

---

## Principios del Roadmap

1. **Un paso a la vez** — No brincar fases, cada una tiene su razon.
2. **Consistencia > Intensidad** — 30 minutos diarios valen mas que 5 horas un sabado.
3. **Documentar todo** — Lo que no esta escrito no existe en el sistema.
4. **Revisar y ajustar** — El roadmap se actualiza cada mes.
