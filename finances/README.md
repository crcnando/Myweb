## Como Registrar desde el Celular

1. Abre GitHub Mobile
2. Ve a `finances/personal/` o el area correspondiente
3. Abre el archivo del mes actual (ej: `2026-07-gastos.md`)
4. Edita y agrega la transaccion
5. Haz commit con mensaje: `finanzas: gasto restaurante $45k`

---

*Actualizar DIARIAMENTE. 2 minutos al dia = control total de tus finanzas.*
